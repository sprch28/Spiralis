# Spiralis

A custom HPC utilities library

Until V1.0 is released, the library is unsafe to use and therefore should be treated with caution.

## Compatibility
* **Little-endian**: Spiralis currently only allows little-endian systems.
* **MacOS**: Should compile cleanly. Newer ARM Chips can leverage SIMD acceleration.
* **Linux**: Compiles cleanly with clang and GCC.
* **Windows**: Compiles when using MinGW: Currently in the process of adding MSVC Compatibility

> **Status:** Active Development
